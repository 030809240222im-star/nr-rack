## はじめに

このアプリで、各階のNRボックス(スクラップ台車)の台数と搬出希望を入力すると、回収日が自動で振り分けられ、搬出日の2日前に確定します。確定した予定と当日のお知らせは、カレンダーで確認できます。下のQRコードを読み取ると、アプリが開きます。

[[QR]]

2つのアプリは使い方が同じです。両方使う場合は、それぞれで会社名を登録してください。スマートフォンのホーム画面に追加しておくと便利です。

## かんたん表示とくわしく表示

アプリは最初「**かんたん表示**」で開きます。上の3つのボタンで切り替えます。

- **よてい**: つぎに出す日と、「○階の○台を EV○前に置く」が大きく出ます。置いたら「**置きました**」を押します(押し間違えたら、もう一度押すと取り消せます)。そのあとの予定と、いま入れてある台数も出ます。
- **台数**: 階ごとに「**いまある**」と「**出したい**」の台数を −/＋ で入れます。入れた数字は自動で保存されます。ない階は「ほかの階を足す」で足します。
- **お知らせ**: 予定が決まった・変わったなどのお知らせです。読んだら「**見ました**」を押します(管理者に伝わります)。

もどしてほしい階を変える、先に出したい階を決める、NRボックスを追加で注文する、参加コードを見るときは、上の「**くわしく表示へ**」を押します。今までの画面(カレンダー・業者入力)になります。「かんたん表示へ」で戻ります。どちらで開くかは、その端末に覚えておきます。この説明書のこのあとの章は、くわしく表示の説明です。

## はじめての登録

登録は1回だけで、終わったその場で使えるようになります。

1. URLを開き、「新規登録はこちら」を押します。
2. メールアドレスとパスワード(6文字以上)を入れて「新規登録」を押します。Googleアカウントがあれば「Googleアカウントでログイン」でも構いません。LINEなどのアプリの中で開いたときは、Googleアカウントでのログインはできないので、メニューの「ブラウザで開く」で開き直すか、メールアドレスで登録・ログインしてください。
3. 「業者登録」の画面で、どちらかを選びます。
    - **会社として初めて使う**: 「新しく登録」で会社名(必須)、お名前、メールアドレス(必須)を入れて「登録する」を押します。
    - **同じ会社の人がすでに使っている**: 「参加コードで入る」で、その人から聞いた参加コード(6文字)、お名前、メールアドレスを入れて「この会社に参加する」を押します。
4. 上に「業者」と出て、「カレンダー」と「業者入力」のタブが出れば完了です。

## 同じ会社の人と一緒に使う

同じ会社の人は、何人でも同じ会社として一緒に使えます。台数・予定・追加注文・お知らせは会社で共通で、だれが入力しても全員の画面に同じ内容が出ます。

- 「業者入力」の上に、会社の**参加コード**(例: A7K2X9)が出ています。新しく加わる人に伝え、登録のときに「参加コードで入る」で入れてもらいます。
- 参加コードが出ていないときは「参加コードを作る」を押します。
- 「配置した」「確認した」などには、会社名と押した人の名前が記録されます。
- 先に「新しく登録」で別の会社として登録してしまったときは、自分で同じ会社に入り直せます。「業者入力」の「別の会社の参加コードを入れる」を押し、同じ会社の人から聞いた参加コードを入れて「コードを確かめる」→「(会社名)に参加する」を押します。自分が入れていた台数は、参加先にまだ入力のない階だけ引き継がれます。同じ会社の人がほかにもいる会社から移るときは、「いまの会社の入力(台数)を引き継ぐ」のチェックを外してください(残る人たちの台数はそのまま残ります)。
- 自分でできないときや、別の会社として登録してしまったときは、管理者に連絡すると1つの会社にまとめてもらえます。

2回目からは、同じメールアドレスとパスワードで「ログイン」します。パスワードを忘れたときは、メールアドレスを入れて「パスワードを忘れた」を押すと、再設定のメールが届きます。

## 台数を入力する(業者入力)

「業者入力」タブで、各階の保有台数と、その階から出したい台数を入れます。入力は自動で保存されます。数字の欄は、左の「−」・右の「＋」を押すと1ずつ増減でき、押し続けると続けて増減します(続けて何回か押すことができ、最後に押してから0.6秒たつと保存します)。

1. 階(1〜62階)ごとに「保有台数」を入れます。
2. 搬出したい階は「出したい台数」を入れます。保有台数より多いと「保有を超えています」と表示されるので、どちらかを直してください。
3. 搬出後に同じ階へ戻してほしくないときは、「同じ階」のチェックを外して、戻してほしい階と台数を入れます。複数の階に分けたいときは「＋戻し先を追加」を押して、階と台数を足します(例: 18階へ2台、20階へ1台)。合計は出したい台数までで、入れなかった残りは同じ階に戻ります。「×」でその戻し先を消せます。
4. 先に出してほしい階があるときは、その階の「先に出す」に☑を付けます。「順位」(1が最初)と、先に出す「台数」を入れられます。台数を出したい台数より少なくすると、その台数だけを先に出し、残りは通常の順番になります。出したい台数より多く入れると、出したい台数も同じ数に増えます。順位は自社の階の中での順番で、ほかの業者との順番は変わりません。
5. 伝えたいことがあれば「備考」に書きます。

希望を早く入れた階ほど、待ち日数が増えて優先されます。保有台数を全部出したい階は「余力なし・最優先」と表示され、先に回収されます。

管理者が回収曜日を決めている場合は、「回収曜日: 月・木」のように表示されます。その曜日に優先して回収されますが、積載に余裕がある日はほかの曜日にも回収することがあります。

1日に午前・午後など複数回回収する日は、カレンダーのマスに「午前・午後」と出ます。日付をタップすると、回ごとに時間・エレベーター・予定が並びます。自社の予定は回ごとに「配置した」にチェックします。

祝日の週は、曜日の決まりをやめて、全業者がほぼ同じ台数になるように割り振られます(カレンダーの祝日には赤い「祝」が付きます)。そのため、決まった曜日と違う日に回収されることがあります。確定した予定は、カレンダーとお知らせで確かめてください。

次のときは台数が自動で変わるので、自分で直す必要はありません。

- 管理者が台数を追加したとき: その階の保有台数が増えます。
- 回収後、盛替え業者か管理者が「戻した」にしたとき: 回収した階の出したい台数と保有台数が減り、戻した階の保有台数が増えます。

## NRボックスを追加で注文する

足りない階があるときは、「業者入力」の表で、その階の「追加希望数」に欲しい台数を入れます。それだけで注文になります。

1. 階の行の「追加希望数」に台数を入れます。横の「備考(追加)」に「受付中 3台」と出ます。台数を直すと注文も直り、0にすると取り消せます。
2. 管理者が、どの日の搬出車で用意するかを決めると、備考が「追加予定 11/1(日)に3台」に変わります。
3. 上げ終わると備考が「✅ 追加済み 11/1(日)に3台」に変わり、その階の保有台数が自動で増えます。

手配と上げた報告は、カレンダーの一番上の「📦 追加注文のお知らせ」にも出ます。希望日やメモを付けたいときは、表の下の「追加注文」の欄から注文することもできます。

## 予定の確定・変更のお知らせ

予定が確定したとき、確定後に変わったとき、取り消しになったとき、当日に連絡(EVの故障・回収車の遅れ・中止など)があったときは、カレンダーの一番上にお知らせが出ます。変更のお知らせは「変更前: 9階 2台(EV1前)、6階 2台(EV1前) → 変更後: 9階 2台(EV1前)」のように、変更前と変更後の全部を並べて出します。同じお知らせが短い間に重なって出たときは、1件にまとめて表示します。

| 表示 | 中身 |
| --- | --- |
| 📋 確定(青) | 予定が確定した(日付・時間・階・台数・置くEV) |
| ⚠ 変更(赤) | 確定後に台数・階・EV・時間が変わった(変更前 → 変更後) |
| ✖ 取り消し(赤) | その日の回収が取り消しになった |
| 📣 連絡(赤) | 当日の連絡(EVの故障・回収車の遅れなど) |

内容を確かめたら、それぞれの「確認した」を押してください。押すとお知らせが消え、管理者に「確認した」と伝わります。管理者がLINE通知を設定している場合は、毎朝6時台に当日・翌日の予定がLINEにも届きます。

**メールでのお知らせ**: 管理者がメールを設定している場合は、登録したメールアドレスに次のメールが届きます(同じ会社の人全員に届きます)。

- 搬出日の前日 13:00: 明日の搬出予定(階・台数・エレベーター・前日に移す階)
- 搬出日の当日 6:30: 今日の搬出予定
- 搬出日から3日たってもアプリを開いていないとき: 台数の確認のお願い(アプリの「業者入力」で台数に違いがないか確かめてください)

## メールのお知らせ

自社へのお知らせ(予定の確定・変更・取りやめ、当日の連絡、盛替え業者の搬出確認の「無い」「不足」)は、登録したメールアドレスにも届きます。10分ごとにまとめて送るため、出来事から届くまで10〜20分ほどかかります(遅れることがあります)。同じ会社で利用中の人全員に届きます。届かないときは、迷惑メールのフォルダも確かめてください。メールが届いても、アプリの「確認した」は押してください。

## カレンダーとお知らせ

「カレンダー」タブを開くと、一番上に大事なお知らせが出ます。

| 表示 | 中身 |
| --- | --- |
| ⚠ 予定の変更・連絡があります(赤) / 📋 予定が確定しました(青) | 確定・変更・取り消し・当日の連絡。「確認した」を押すと消える |
| 📝 連絡(備考)(青) | 揚重業者・管理者から、今日・明日の搬出についての連絡 |
| ⚠ 盛替え業者からの連絡(赤) | 運んだはずのものが「無い」「不足」と報告された。至急運ぶ |
| ↩ 戻しのお知らせ(緑) | 搬出した分を戻した階・台数・エレベーター(3日間表示) |
| 📦 追加注文のお知らせ(青) | 追加注文をいつの搬出車で用意するか、いつ上げたか |
| 🔔 本日は搬出日です(オレンジ) | 今日の階・台数・置くエレベーター |
| 📅 明日は搬出日です(青) | 明日の予定。「今日中に移動」は今日のうちに指定の階へ移す |

カレンダーの日付は、色で自社の搬出日が分かります。

| 色 | 意味 |
| --- | --- |
| オレンジ | 今日が自社の搬出日 |
| 青 | 自社の搬出日(確定済み)。台数と時刻も出ます |
| 緑 | 搬出可能日(回収日だが自社の分はまだ確定していない) |
| 灰色 | 回収なし |

日付をタップすると、その日の回収時間・台数・エレベーター、回収する業者と台数が下に出ます。予定は搬出日の2日前に自動で確定します。確定した自社の予定は、下の「自社の搬出予定」に並びます。

## 搬出日の流れ

搬出日には、指定のエレベーター前まで運んで「配置した」にチェックします。そのあとは盛替え業者が確かめて搬出し、戻します。

1. 「自社の搬出予定」で、日付・時間・階・台数・集積場所(「EV1前」など)を確認します。
2. 「前日までに移動」と書かれた行は、その階に搬出EVが停まりません。回収日の前日までに、指定の階のEV前へ移しておきます。
3. 当日、集積場所のEV前まで運びます。
4. 「配置」の欄で、実際に置いたエレベーター(EV1、EV2など)を選びます。
5. 「配置した」にチェックします。「配置済み」「EV2に配置」のように表示されれば完了です。置くエレベーターは、すべてのエレベーターから選べます。管理者が指定したエレベーター以外を選ぶと「(指定外)」と表示され、置いたあとに管理者と盛替え業者に通知されます。

間違えたときは、エレベーターを選び直すか、チェックを外します。スマートフォンでは、表が1件ずつのカードになって全部の欄が縦に並びます。

盛替え業者が置き場所で台数を確かめ、「搬出確認」の欄に結果が出ます。

- **✅ 揃っている**: 問題ありません。
- **⚠ 無い / ⚠ 不足**: カレンダーの一番上に赤い枠で通知が出ます(例: 3台のうち1台しかありません)。至急、指定のエレベーター前へ運んでください。運ぶと盛替え業者が確かめ直し、通知が消えます。

揚重(盛替え)業者や管理者が戻すと、カレンダーの一番上に「↩ 戻しのお知らせ」(緑)が出ます。例:「10/31に搬出した5階の4台 → 9階へ4台戻しました(EV1)」。「戻し」の欄にも「✅ 戻し済み」と使ったEV・台数が出て、「業者入力」の台数も自動で更新されます。

## 最新にする・困ったとき

確定した内容や連絡は、開いたままでも自動で反映されます。反映されないときは、画面上部の「↻ 最新にする」を押すか、画面を下に引っぱってください。横の「10:32 更新」は、最後にデータを受け取った時刻です。

| こんなとき | すること |
| --- | --- |
| ログインできない | メールアドレスとパスワードを確かめる。忘れたときは「パスワードを忘れた」 |
| 「このメールアドレスは登録済みです」 | 新規登録ではなく「ログイン」から入る |
| 「利用が停止されています」 | 管理者に連絡する |
| 登録したのに画面が切り替わらない | 「↻ 最新にする」を押す |
| 予定が出ない | まだ確定していない(通常は搬出日の2日前)。「↻ 最新にする」でも出なければ管理者に確認 |
| 赤い通知が消えない | 運んだあとは盛替え業者が確かめ直すまで残る。急ぎのときは管理者に連絡 |
| 「未送信 ○件」と出る | 電波がない。入力はスマートフォンに残っていて、つながると自動で送られる。画面は閉じても大丈夫 |
| 「保存できませんでした」 | 通信を確かめて読み込み直し、もう一度入力 |

終わるときは「ログアウト」を押します。自分のスマートフォンなら、ログインしたままでも構いません。

**自動で最新になります**: ログインしている画面は、3分ごとに自動で読み込み直します。見ていたタブと日付、「入力のある階だけ表示」などの表示のチェックは、そのまま残ります(表示のチェックは、その端末に覚えておきます)。画面をさわってから1分以内は、読み込み直しません。入力欄にカーソルがあるとき、確認の途中、送信を待っている変更があるとき、画面が裏にあるときは、読み込み直しません。すぐ最新にしたいときは、上の「↻ 最新にする」を押します。
