## はじめに

このアプリで、搬出日の業者・階・台数・エレベーターを確かめ、搬出の確認と戻しの完了を入力します。入力した内容は、管理者と各業者のアプリにすぐ届きます。下のQRコードを読み取ると、盛替え業者用のページが開きます。

[[QR]]

管理者が不停止階の盛替えを指示すると、「搬出予定」の上に「盛替えの指示があります」が出ます。書かれた盛替え日(日付がないものは回収日の前日まで)に、書かれたEV前の階へ盛替えてください(毎朝のLINEにも載ります)。

2つのアプリは使い方が同じです。両方担当する場合は、それぞれで登録してください。業者用のURL(末尾に crew/ がないもの)ではなく、必ずこの盛替え業者用のURLを開いてください。

## 簡単表示と詳しい表示

スマホ・タブレットでは最初「**簡単表示**」、パソコンでは最初「**詳しい表示**」で開きます。その日の作業が大きなカードで出ます。業者は**階の上から順**に並び、新しいBOXの搬入はその下に出ます(詳しい表示の「搬出予定」も同じ並びです)。日付のボタンで、ほかの日に切り替えられます。上に「確かめた 1/4・戻した 0/4・入れた 0/1」のように進み具合が出ます。

1. **出すBOXの確かめ**: 台数を確かめて、「**揃っている**」「**足りない**」(あった台数を入れて「これで送る」)「**ない**」のどれかを押します。「足りない」「ない」は業者と管理者にすぐ伝わります。押し間違えたら「なおす」を押します。
2. **戻し**: 確かめたあと、戻したエレベーターを EV のボタンで選び、「**○階の EV○前へ 戻しました**」を押します。業者の台数が変わります。もう一度押すと取り消せます。
3. **📦 新しいBOXの搬入**: 業者名・階・台数が出ます。使うエレベーターを EV1〜 のボタンで選び、入れたら「**EV○で 入れました**」を押します。業者の台数が増えます。

戻し一覧や追加注文の状況を見るときは、上の「**詳しく表示へ**」を押します。今までの画面(搬出予定・戻し一覧・追加注文)になります。「簡単表示へ」で戻ります。この説明書のこのあとの章は、詳しい表示の説明です。

## はじめての登録

登録は1回だけで、終わったその場で使えるようになります。

1. 盛替え業者用のURLを開きます。ログイン画面に「盛替え業者用」と出ていることを確かめます。
2. 「Googleアカウントでログイン」を押すか、「新規登録はこちら」からメールアドレスとパスワード(6文字以上)でアカウントを作ります。LINEなどのアプリの中で開いたときは、Googleアカウントでのログインはできないので、メニューの「ブラウザで開く」で開き直すか、メールアドレスで登録・ログインしてください。
3. 「盛替え業者の登録」で、会社名(必須)、お名前、メールアドレス(必須)を入れて「登録する」を押します。同じ会社の人も、1人ずつ同じ会社名で登録します(押した操作には「会社名 名前」が記録されます)。
4. 上に「盛替え業者」と出て、「搬出予定」「戻し一覧」「追加注文」のタブが出れば完了です。

2回目からは、同じURLで同じアカウントにログインします。スマートフォンのホーム画面に追加しておくと便利です。

## カレンダーと当日のお知らせ

「搬出予定」タブを開くと、一番上に当日と翌日の搬出が大きく出ます。

| 表示 | 中身 |
| --- | --- |
| 🔔 本日は搬出日です(オレンジ) | 当日の業者・階・台数・エレベーター。業者が配置済みの行には「✅ 配置済み」 |
| 📅 明日は搬出日です(青) | 翌日の予定 |
| ⚠ 盛替え業者からの連絡(赤) | 「無い」「不足」を入れて、まだ片付いていない行 |

カレンダーでは、当日の回収日がオレンジ色です。各日には、台数・開始時間・エレベーターと、配置と戻しの進み具合(例: 配置2/3 戻し0/3)が出ます。日付をタップすると、その日の予定が下に1行ずつカードで並びます。

1日に午前・午後など複数回回収する日は、日付をタップすると回ごとの予定が並びます。搬出の確認と戻しの✅も回ごとに付けます。

夜間の作業に合わせて、朝6時から翌朝5時59分までを同じ日として扱います(例: 11/18の3時は、11/17の作業として「本日は搬出日です」に出ます)。

予定は、搬出日の2営業日前(土日祝を除く。月曜の回収なら前の週の木曜)に管理者側で確定します。確定前の日は「確定すると表示されます」と出ます。

## 指定外のエレベーターに置かれたとき

業者は置くエレベーターを全部のEVから選べます。管理者が指定したEV以外に置かれると、カレンダーの一番上に「⚠ 指定外のエレベーターに置かれています」と出て、行にも「指定外のEV」と出ます。現場を確かめて、運び直すか、そのままでよいときは「確認した」を押してください(押すと管理者の画面からも消えます)。

## プッシュ通知(端末に通知を受け取る)

届くもの: 回収日の予定の確定・変更・取りやめと、盛替えの指示。

1. **iPhone・iPad**: Safariでアプリを開き、共有ボタン(□に↑)→「ホーム画面に追加」を押します。ホーム画面に追加したアイコンからアプリを開きます(iOS 16.4以降。Safariの画面のままでは届きません)。パソコン・Androidは、ChromeやEdgeでそのまま開きます。
2. 画面上の「🔔 通知を受け取る」を押し、「許可」を押します。
3. ボタンが緑の「🔔 通知オン」になれば完了です。10〜20分ほどで「通知の設定ができました」が届きます。
4. やめるときは「🔔 通知オン」を押し、「もう一度押すと通知を止める」を押します。

通知は10分ごとにまとめて送るため、出来事から届くまで10〜20分ほどかかります(GitHubの都合で、もっと遅れることがあります)。端末ごとに設定します。同じ端末でNRボックス版とスクラップ版の両方を使う場合、通知の登録は共通です。届かないときは、端末の「設定」→「通知」で、このアプリ(またはブラウザ)の通知が許可されているか確かめてください。

## メールのお知らせ

回収日の予定が確定・変更・取りやめになったとき(その日の予定の全部つき)と、管理者から盛替えの指示が出たときは、登録したメールアドレスにも届きます。10分ごとにまとめて送るため、届くまで10〜20分ほどかかります(遅れることがあります)。

## 新しいBOXの搬入

管理者が追加注文を手配した日は、その日の予定の上に「📦 新しいBOXの搬入」が出ます。業者名・搬入する階・台数が出るので、使うエレベーターを選び、実際に入れた台数を確かめて「**入れた**」を押します。押すと「✅ 入れた」になり、その業者の台数(その階の保有)が増え、業者のアプリにも届きます。押し間違えたときは管理者に伝えてください(管理者が取り消せます)。

## 管理者・業者からの連絡

管理者から盛替え業者あてに連絡が来ると、アプリの上に「✉ 管理者からの連絡」として7日間出ます(通知を受け取る設定をしていれば、端末にも届きます)。業者から盛替え業者あてに連絡が来ると「✉ 業者からの連絡」として出ます。読んだら「見ました」を押すと、送った業者に伝わります。

## 搬出の確認

搬出エレベーター前で台数を確かめ、カードごとに結果を入れます。各カードの上に「A社 5階 4台 → EV1前」のように、業者・階・台数・置き場所が出ます。「配置」の欄で、業者が運び終えたか(「✅ 配置済み(EV2)」か「未配置」)も分かります。

| 状況 | 押すもの |
| --- | --- |
| 予定どおり揃っている | 「揃っている」 |
| 1台も無い | 「無い」 |
| 足りない | 「実数」に実際にあった台数を入れて(左右の「−」「＋」でも増減できます)「不足」 |
| 押し間違えた | 「取消」 |

「無い」「不足」を押すと、その業者のアプリの一番上に赤い枠ですぐに通知されます。例:「⚠ 盛替え業者からの連絡 10/30 8階 → EV1前: 3台のうち1台しかありません(不足2台)」。管理者の画面にも同じように出ます。

業者が運び直したら、もう一度確かめて「揃っている」を押します。そうすると赤い通知が消えます。そのまま戻しまで完了した場合も消えます。

## 連絡(備考)と追加注文の状況

- **連絡(備考)**: 日付をタップした画面の下の「連絡(備考)」に書いて「連絡を書く」を押すと、その日に搬出がある業者と管理者のアプリに出ます(例: EV1前が混雑しています。11時以降に運んでください)。書いた連絡は、その日の画面と、当日・前日のお知らせに並びます。
- **業者の備考**: 業者が「業者入力」に書いた備考は、各カードの「業者の備考」に出ます。
- **追加注文**: 「追加注文」タブで、業者の追加注文の状況(受付中・どの日の搬出車で用意するか・いつ上げたか)を見られます。手配と「上げた」の入力は管理者が行います。

## 電波が弱い場所での入力

電波がない場所で押した操作はスマートフォンに残り、つながったときに自動で送られます。送れていない間は、画面上部に「未送信 ○件」と出ます。何人かで同じ日の別の行を同時に操作しても、互いに消し合いません。

このアプリでできるのは、搬出予定と追加注文の状況を見ること、搬出の確認(揃っている・無い・不足)、戻しの✅、連絡(備考)を書くことです。予定の変更・追加注文の手配は管理者が行います。

## 戻し一覧と完了✅

「戻し一覧」タブに、この1週間から今日までに搬出した分が、戻し階・業者・台数で並びます。未完了のものが上に来て、上部に未完了の件数が出ます。

業者が戻し先を複数の階に分けているときは、「18階 2台」「20階 1台」のように階ごとの台数が出ます。その台数どおりに各階へ戻してから✅を付けてください。✅を付けると、それぞれの階の台数に分けて反映されます。

1. 「戻し階」(大きい数字)の階へ戻します。「同じ階」とあるものは、搬出した階へ戻します。
2. 戻したエレベーターを、「○階の [EV] 前に」の欄で選びます(階は業者が決めた戻し階です)。最初は業者が置いたEVになっています。
3. 戻したら「戻した」にチェックします。完了✅になります(行の場所は動きません。完了した行は少し薄く表示されます)。チェックした後でも、エレベーターは選び直せます。
4. 台数は搬出した台数が自動で入ります。違うときは管理者に伝えてください。

「戻した」にすると、その業者のアプリに「↩ 戻しのお知らせ」が出て、業者の台数が自動で変わります(その階の「出したい台数」が搬出した分だけ減ります。保有台数は、同じ階へ戻したときは変わらず、別の階へ戻したときは搬出した階が減って戻した階が増えます)。押し間違えたときは、チェックを外すと元に戻ります。カレンダーの日付のカードにある「戻した」も同じものです。

## 困ったとき

画面が古いときは、上部の「↻ 最新にする」を押すか、画面を下に引っぱってください。

| こんなとき | すること |
| --- | --- |
| タブが「登録」だけになる | 登録がまだ。会社名を入れて「登録する」 |
| 「業者登録」や「業者入力」の画面になる | 業者用のURLを開いている。末尾に crew/ が付いたURLを開き直す |
| 「利用が停止されています」 | 管理者に連絡する |
| 予定が出ない | まだ確定していない。「↻ 最新にする」でも出なければ管理者に確認 |
| 「未送信 ○件」と出る | 電波がない。入力は残っていて、つながると自動で送られる |
| 「保存できませんでした」 | 通信を確かめて読み込み直し、もう一度入力 |

このアプリでは全業者の搬出予定が見えます。URLやログインしたスマートフォンを、関係のない人に渡さないでください。

**自動で最新になります**: ログインしている画面は、3分ごとに自動で読み込み直します。見ていたタブと日付、「入力のある階だけ表示」などの表示のチェックは、そのまま残ります(表示のチェックは、その端末に覚えておきます)。画面をさわってから1分以内は、読み込み直しません。入力欄にカーソルがあるとき、確認の途中、送信を待っている変更があるとき、画面が裏にあるときは、読み込み直しません。すぐ最新にしたいときは、上の「↻ 最新にする」を押します。
