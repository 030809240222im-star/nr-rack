## はじめに

このアプリは、業者が入力した各階の保有台数と搬出希望をもとに、回収日ごとの回収先を自動で振り分け、搬出日の2日前に自動で確定します。管理者は回収日・台数・エレベーターを決め、必要なときだけ確定後に変更します。

NRボックス用とスクラップ用の2種類があり、使い方は同じです。データは別々に保存されます。

## かんたん表示とくわしく表示

管理者の画面は最初「**かんたん表示**」で開き、「**きょうやること**」が出ます。本日の回収(置いた・もどした数、足りない/ないの件数)、これから7日の決まっていない回収日、新しい追加注文、不停止階の指示、業者の登録など、やることが一覧になり、「開く」でその画面へ移ります。終わったものは一覧から消えます。上のボタンは「きょうやること・カレンダー・業者の台数・注文と記録・設定」の5つです。

## 業者・盛替え業者の登録

業者も盛替え業者も、URLを開いて会社名を登録するとすぐに使えます。管理者の承認はいりません。

1. 「設定」タブの「このアプリのQRコード」を見せるか、「URLをコピー」で業者に送ります。盛替え業者には、その下に出ている盛替え業者用のURL(末尾が crew/)を伝えます。取扱説明書(PDF)にもQRコードが付いています。
2. 登録すると、「登録」タブの「利用中の業者」または「利用中の盛替え業者」に出ます。業者は会社ごとにまとまり、会社名・参加コード・メンバー(名前とメールアドレス)が並びます。
3. 心当たりのない登録や、辞めた人・取引が終わった相手は「この人を停止」(盛替え業者は「利用を停止」)を押します(確認のため、もう一度押すと停止)。同じ会社のほかの人はそのまま使えます。停止された人は、自分で登録し直すことはできません。
4. 停止した相手は「利用停止中・未完了」に移ります。「利用を再開」で元に戻せます。

揚重・盛替え業者のアプリは管理者のアプリとは別で、できるのは搬出予定と追加注文の状況を見ること、搬出の確認(揃っている・無い・不足)、戻しの✅、その日の連絡(備考)を書くことです(✅を付けると業者の台数も自動で変わります)。予定の変更・追加注文の手配・確認付きの連絡はできません。URLは盛替え業者にだけ伝え、知らない登録が出たら停止してください。NRボックス用とスクラップ用は登録も別です。

### 最終ログイン

「登録」タブで、業者の一人ひとり・盛替え業者・管理者ごとに**最終ログイン**(アプリを最後に開いた日時)が見られます。アプリを開いたときと、ほかのアプリから画面に戻ったときに記録されます(5分以内の繰り返しは数えません)。この機能を入れる前のログインや、まだ一度も開いていない人は「記録なし」と出ます。

### 同じ会社の複数の人

- 業者は、会社として最初に登録した人のアプリの「業者入力」に出る**参加コード**を、同じ会社の人に伝えます。2人目からは登録のときに「参加コードで入る」でそのコードを入れると、同じ会社になります。台数・予定・追加注文・お知らせは会社で共通です。
- 「登録」タブの会社欄で、参加コードを作ったり作り直したりできます(作り直すと古いコードは使えなくなります)。会社名を直すと、メンバー全員の会社名が変わります。
- 別々に登録してしまった同じ会社は、まとめたい会社の欄で「まとめ先」を選び、「この会社を左の会社にまとめる」を2回押します。メンバー・各階の台数(足し合わせ)・配置・追加注文・追加記録・お知らせ・確定の行・回収曜日が、まとめ先に移ります。
- 業者は、別の会社として登録した後でも、自分のアプリの「業者入力」→「別の会社の参加コードを入れる」で参加コードを入れると、その会社に入り直せます。入力していた台数は、参加先にまだ入力のない階だけ引き継がれます。入り直した人しかいなかった会社は、一覧から消えます。
- 会社の全員が別の会社に参加したあとに残った記録は、「登録」タブの「メンバーのいない会社の記録」に出ます。台数をすでに引き継いでいるときは「台数は移さず片付ける」、そうでないときは「台数を足して移す」を、移す先の会社を選んで押します(2回押すと実行)。
- 会社の一覧の名前は、いまその会社にいる人の会社名です。会社の代表(最初に登録した人)がほかの会社に移っても、残った人の会社は元の名前のまま表示されます。
- 揚重・盛替え業者は、同じ会社でも1人ずつ登録します。履歴や確認には「会社名 名前」が記録されます。

## 設定

使い始める前に、「設定」タブで次の項目を確かめます。入力は自動で保存されます。アプリの数字の欄は、どれも左の「−」・右の「＋」で1ずつ増減でき、押し続けると続けて増減します。続けて何回か押すことができ、最後に押してから0.6秒たつと保存します。

| 項目 | 初期値 | 意味 |
| --- | --- | --- |
| 車輌1台あたりの上限 | NR 4台 / スクラップ 20台 | 回収日の台数を車輌数から決めるときの1台分 |
| 逼迫度の重み | 1 | 保有台数に対する搬出希望の割合(%)をどれだけ重く見るか |
| 待機日数の重み | 15 | 希望を出してから待った日数をどれだけ重く見るか |
| 保有台数の重み | 2 | その階の保有台数をどれだけ重く見るか |
| 余力なしとみなす逼迫度 | 100% | この割合以上の階は「余力なし」として最優先で回収 |
| 自動確定(搬出日の何日前) | 2日前 | この日になると配分を自動で確定。0で自動確定しない |

優先順は、まず「余力なし」の階、次に評価点が高い順です。評価点 = 逼迫度×重み + 待機日数×重み + 保有台数×重み。例えば5階で保有2台・希望2台なら逼迫度100%で、余力なしになります。

業者は、出した分の戻し先を複数の階に分けて指定できます(例: 18階へ2台、20階へ1台、残りは同じ階)。確定した予定・盛替え業者の「戻し一覧」・メールには「18階 2台・20階 1台」のように出て、戻しの✅を付けると、それぞれの階の保有台数に分けて足されます。

業者は「業者入力」で、先に出してほしい階に「先に出す」の☑と順位・台数を付けられます。付けた階は、その業者の分の中で先に回収します(順位1から。台数を指定したときはその台数だけ先に)。業者どうしの順番は評価点のままで変わりません。「優先順位」タブには「業者の先行○番」と出ます。管理者が業者の代わりに付けることもできます。

**建物の設定**では、最下階・最上階とエレベーターの台数(最大12台)を変えられます。業者が入力できる階と、選べるEV(EV1〜)の数が変わります。

**エレベーターごとの停止階**では、EV1〜5ごとに動く階の範囲と不停止階を入れます。不停止階は「13,14,44-46」のように、カンマと範囲で入力します。

**業者ごとの回収曜日**では、業者ごとに日〜土の回収する曜日にチェックを入れます。曜日を何も選ばない業者は、どの曜日でも回収します。振り分け方は「振り分けと自動確定」を見てください。

「サンプルを入れる」で架空のデータを入れて操作を試せます。試したあとは「サンプルを消す」で、実際のデータを残したまま消せます。本番と切り離して試すなら、お試し版を使うと安心です。

「全データのリセット」は、試しに入れたデータを全部消して使い始める前の状態に戻します。入力欄に「リセット」と入れて「全部消す」を押します。回収日・確定・業者の入力・追加注文・追加と戻しの記録・お知らせ・業者と揚重業者の登録(停止した人も含む)・参加コードが消え、設定と管理者は残ります。元に戻せないので、本番が始まってからは使わないでください。NRボックスとスクラップは別々にリセットします。

## 回収日を作る

「カレンダー」タブで日付をタップし、その日を回収日にします。台数とエレベーターを入れると、すぐに配分の見込みが下に出ます。

1. 日付をタップして「この日を回収日にする」を押します。
2. 「回収車輌」の − / ＋ で台数を決めます。回収できる台数は車輌数×上限です。
3. 「回収時間」の開始と終了は、左右の「−」「＋」で5分ずつ変えられます(押し続けると続けて動きます)。数字で「930」と打つと09:30、「1030」は10:30、「10」は10:00になります。
4. 「集積するエレベーター前」で使うEVにチェックを入れます。複数選べます。各階は、選んだ中でその階に停まるEVに割り当てられます。
5. 下の表で、順位・業者・階・台数・集積EVを確認します。

**不停止階の一覧**: 「不停止階」タブに、「設定」で決めた不停止階(どれかのEVが停まらない階)と、どのEVも停まらない階に台数を持っている業者が、業者・階・保有/希望台数・逼迫度・停まらない理由の一覧で出ます。「停まらない理由」には、たとえば「11/16(月)の回収EV(EV1)は5階に停まりません」と、停まるEV・停まらないEVが出ます。iPadの横向きやパソコンでは横に並ぶ表で、スマホやiPadの縦向きでは1行ずつのカードで出ます。搬出の希望がなくても、台数を持っていれば出ます。回収日のエレベーターが停まらず配分に入れない希望は上に並びます(「余力なし」が先)。タブの赤い数字は、そのうち、まだ集積指示を出していない行の数です。一覧の各行で、「回収日(カレンダーから選びます。確定前の回収日だけ指示できます)・盛替え日(今日から回収日までの日をカレンダーで選びます。初期値は回収日の前日)・EV(すべてのEVから選べます)・盛替え先の階」を選んで「指示して通知」を押すと、盛替え日に、そのEV前の指定の階へ盛替える指示になります。回収日を選び直すと、盛替え日はその前日に変わります。盛替え先の階は、EVを選ぶと、そのEVが停まるいちばん近い階に自動で入ります(変えられます)。指示は盛替え業者の「搬出予定」画面の「盛替えの指示があります」に出て、毎朝のLINEにも載ります。すでに出した指示は行に出て、「外す」で取り消せます。

選んだEVが停まらない階でも、緊迫している場合は**集積指示**で回収できます。集積指示は「不停止階」タブの一覧だけで出します(日ごとの画面には出ません)。業者には「前日までに移動」と表示され、前日のお知らせにも「今日中に移動」と出ます。取りやめるときは一覧の「外す」を押します。集積するEVは、その日に指定したEV以外も含め、すべてのEVから選べます。指定外のEVを選んでも、そのEVはその日の指定として扱われるので、業者がそこに置いても「指定外のエレベーターに置かれています」の通知は出ません。

回収をやめる日は「この日を回収なしに戻す」を押します(確認のため、もう一度押すと削除)。

**1日に複数回(午前・午後など)回収するとき**: 回収日の画面の上にある「＋ 午前・午後など、回を追加」を押します。1回目は「午前」、追加した回は「午後」という名前になり、「この回の名前」で変えられます(午前・午後・夕方などの候補が出ます)。
- 回ごとに、回収できる台数・回収時間・エレベーターを別々に設定します。追加したとき、台数とエレベーターは直前の回と同じ値が入ります。
- 画面の上の回の名前のボタンで、見る回を切り替えます。確定・取り消し・再振り分け・連絡も回ごとに行います。「この回を削除」でその回だけ消せます。
- 割り振りは1回目から順番に行い、1回目で出した台数は2回目に回りません。自動確定も回ごとに、搬出日の2日前に行います。
- カレンダーのマスには、その日の全部の回を合わせた台数と、「午前・午後」の名前が出ます。業者と盛替え業者の画面には、回ごとの予定が並びます。
- 前日・当日のメールとLINEには、回ごとの時間と内容がまとまって出ます。

## 振り分けと自動確定

配分は業者の入力に合わせて変わり続け、搬出日の2日前に自動で確定します。確定すると、各業者の「自社の搬出予定」と盛替え業者の画面に日付・時間・階・台数・集積EVが出ます。

**振り分けの順番**

1. その曜日に割り当てた業者(曜日を決めていない業者も含む)を、「余力なし」→ 評価点の高い順で入れます。
2. 積載に余裕が残ったら、ほかの曜日の業者を、「余力なし」→ 逼迫度の高い順で入れます。配分表に「曜日外」と出ます。

**祝日がある週**: 業者ごとの回収曜日に使っている曜日に祝日(休日)が当たる週は、その週の業者の曜日を**1日ずつ後ろへずらします**。たとえば月曜が祝日なら、月曜の業者は火曜、火曜の業者は水曜、水曜の業者は木曜、木曜の業者は金曜になります。休日が2日あれば2日ずらします。ずらした先が土曜より後になる業者がいて**その週に収まらないとき**は、その週だけ曜日の指定をやめて、**全業者に等分**します(その週の回収日を日付順に、その週にこれまで回収した台数がいちばん少ない業者から1台ずつ)。日を選ぶと、「祝日がある週のため、業者の曜日を1日ずつずらしています(月曜→火曜・…)」のように出ます。この扱いは「設定」の「祝日の扱い」のチェックで止められます(止めると、祝日でも曜日どおり)。
- 祝日は、日本の祝日(振替休日・国民の休日を含む)をアプリが自動で数えます。カレンダーには赤い「祝」が付きます。
- 「設定」タブの「祝日の扱い」で、等分する機能のオン・オフ、祝日を休みにしない(祝日でも回収する)日の指定、会社の休日(年末年始・夏季休業など)の追加ができます。
- 回収日は今までどおり管理者が作ります。祝日に回収日を作っていなければ、その日は回収しません。

「優先順位」タブで、業者ごと・階ごとの優先順、逼迫度、待機日、評価点、回収予定日を確かめられます。

**自動確定のルール**

| いつ | どうなるか |
| --- | --- |
| 搬出日の3日前まで | 確定しない。配分の見込みが変わり続ける |
| 2日前から | その時点の配分で自動確定。日付の画面に「自動確定」と出る |
| 集積するEVを選んでいない日 | 確定しない。選ぶと確定する |
| 管理者が10分以内に設定を変えた日 | 変えてから10分たってから確定する |
| 自動確定のあと「確定を取り消す」を押した日 | 自動では確定しない。「この日の配分を確定」で確定する |

2日前より早く確定したいときは、日付の画面の「今すぐ確定」を押します。自動確定は、管理者のだれかがアプリを開いたときと、毎朝6時台の自動処理(設定している場合。リポジトリの「毎朝の自動処理の設定.md」)で行われます。自動処理を設定していない場合は、2日前から当日までの間に管理者が一度はアプリを開いてください。

**空きが出たとき**: 確定した日に空きが出て(台数を減らした、行を削除した、など)、その日に回れる希望が残っているときは、「確定と再振り分け」の画面(と、カレンダーのその日の画面)に「**空きが○台あります。逼迫した業者に回しますか?**」と出ます。
- **はい**: 逼迫度の高い順(「余力なし」が先)に、自動で空きを埋めます。
- **いいえ**: 候補の一覧(業者・階・残りの希望・逼迫度・集積)が出るので、追加する業者と階にチェックを付け、台数を入れて「選んだ業者に追加して通知」を押します。
- どちらも、追加された業者にだけ「予定が変わりました」のお知らせが出ます。
- あなたが減らした・削除した業者と階は、同じ日の候補に出ません(減らしたのに、また戻らないようにするため)。
- 「閉じる」を押すと、その空きの数のあいだは出ません。

**曜日の振り分けと開始日**: 「設定」の「業者ごとの回収曜日」の上にある「曜日の振り分けを始める日」から、曜日の指定を使います(初期値は2026年11月16日の月曜日)。それより前の回収日は、これまでどおり、曜日に関係なく全業者を逼迫度の順に割り当てます。始める日以降は、次のように割り当てます。①その曜日の担当業者がいる日は、担当業者どうしで積載を均等に割ります(積載÷担当業者数の台数ずつ。たとえば積載12台で担当が3社なら、4台ずつ。その日に搬出予定がない担当業者も数えます)。希望が少なくて余った分(上の例で、1社の希望が2台なら余りの2台、1社が搬出なしなら余りの4台)や、割り切れなかった分は、逼迫している業者(担当の業者もほかの業者も)から順(余力なしが先)に入れます。②担当業者が1社もいない曜日は、全業者を逼迫している順に割り当てます。曜日を決めていない業者は、担当業者ではなく、余った積載に逼迫している順で入ります。空にすると、すべての日で曜日を使います。確定前でも、「カレンダー」の上に「曜日ごとの担当業者」が出て、日を選ぶと「○曜日の担当: …」が出ます。すでに確定した日は、あとから曜日を設定しても組み直されません。曜日どおりにするときは「確定を取り消す」→「今すぐ確定」を行います(画面にも注意が出ます)。

**自動で最新になります**: ログインしている画面は、3分ごとに自動で読み込み直します。見ていたタブと日付、「入力のある階だけ表示」などの表示のチェックは、そのまま残ります(表示のチェックは、その端末に覚えておきます)。画面をさわってから1分以内は、読み込み直しません。入力欄にカーソルがあるとき、確認の途中、送信を待っている変更があるとき、画面が裏にあるときは、読み込み直しません。すぐ最新にしたいときは、上の「↻ 最新にする」を押します。

**階マップ**: 「階マップ」タブに、最上階から下へ、各階の台数を業者の色で積み上げた図が出ます。「表示」で保有台数と搬出希望を切り替え、「業者」で1社だけに絞れます。「台数のある階だけ表示」にすると、空の階をたたみます。色の上にカーソルを置く(スマホは押す)と、業者名と台数が出ます。階の右には、各EVがその階に停まるか(○×)が出て、どのEVも停まらない階に台数があるときは赤く注意が出ます。棒の長さは、いちばん多い階を100%にした割合です。

**業者の削除**: 「業者入力」タブで業者を選び、「この業者を削除」を押します(確認のため、もう一度押すと削除)。その業者の保有・搬出希望・追加注文・お知らせ・参加コードが消え、今日以降の確定済みの搬出予定と集積指示からも外れます。その会社で登録していた人は利用停止になります(同じ人が登録し直す場合は、「登録」タブの承認待ちから承認すれば、新しい会社として再開できます)。過去の搬出の記録は残ります。元に戻せないので、会社名をよく確かめてから押してください。

**確定後の変更**: 「確定と再振り分け」タブで、台数の変更、行の削除、あとから追加したい業者や急ぎの業者の追加ができます。NRボックスは業者ごとの持ち回りなので、ほかの業者への振り替えはしません。変更は業者と盛替え業者の画面にすぐ反映されます。確定後にEVを変えたときは、取り消してから確定し直してください。

## 回収当日の流れ

当日は、業者が運び、盛替え業者が確かめて戻し、その結果がそれぞれのアプリにすぐ届きます。カレンダーでその日をタップすると、配置・搬出確認・戻しの状況を一覧で見られます。

1. **業者**: 指定のEV前に運び、置いたEVを選んで「配置した」にチェックします。「配置済み(EV2)」のように出ます。置くEVは全部のEVから選べます。あなたが回収日に指定したEV以外に置くと、カレンダーの一番上に「⚠ 指定外のエレベーターに置かれています」と出て(管理者と盛替え業者の両方に)、前日・当日のLINEにも載ります。運び直すか、そのままでよいときは「確認した」を押すと消えます(だれかが押せば全員で消えます)。業者が置き直すと、また通知されます。管理者が代わりにチェックすることもできます。
2. **盛替え業者**: EV前で台数を確かめ、「揃っている」「無い」「不足(実際の台数)」を入れます。「無い」「不足」は、その業者のアプリと管理者の画面の一番上に赤い枠で出ます。管理者も同じボタンで入力できます。
3. **戻し**: 搬出して空になったものを戻したら、盛替え業者(または管理者)が「戻した」に✅を付けます。EVと台数は自動で入ります(業者が置いたEVと搬出した台数)。違うときは管理者が日付の画面で直します。盛替え業者は「戻し一覧」タブで、戻し階ごとにまとめて入力できます。

「戻した」にチェックすると、その業者のアプリに「↩ 戻しのお知らせ」が出て、台数が自動で変わります。

| どこ | 変わり方 |
| --- | --- |
| 回収した階 | 搬出希望と保有台数から、回収した台数を引く |
| 戻し先の階 | 保有台数に、戻した台数を足す(業者が別の階を指定していればその階) |
| 戻した台数を直したとき | 差の分だけ、戻し先の保有台数も直る |
| チェックを外したとき | 変えた分が元に戻る |

例えば、5階で保有6台・希望4台の業者から4台回収し、5階に4台戻すと、保有6台・希望0台になります。「戻した」のあとで確定の台数を直したときは、チェックを一度外して付け直してください。

## 業者へのお知らせと当日の連絡

**業者へのメール**(設定している場合。リポジトリの「毎朝の自動処理の設定.md」の「4. 業者へのメール」): 搬出日の前日13:00に明日の予定、当日6:30に今日の予定を、その会社の利用中の人全員にメールで送ります。搬出日から3日たっても会社のだれもアプリを開いていないときは、13:00に台数の確認をお願いするメールを送ります。「業者を追加」で作ったアプリを使わない業者には送らないので、電話などで連絡してください。送れたかどうかは GitHub の Actions →「mail」のログで確かめられます。

確定したとき(自動確定も含む)、確定後に台数・階・EV・時間を変えたとき、確定を取り消したときは、その業者のアプリに自動でお知らせが出ます。業者は内容を確かめて「確認した」を押します。

- カレンダーで確定済みの日を開くと、「業者へのお知らせ」に送った内容と、業者が確認したか(✅ 時刻 / 未確認)が並びます。
- **当日の連絡**: 同じ画面の「この日の業者全員に連絡」で種類(EVの故障・停止、回収車の遅れ、回収の中止、時間の変更、その他)を選び、内容を書いて「連絡を送る」を押すと、その日の業者全員に届きます。
- **連絡(備考)**: 日付の画面の「連絡(備考)」に書くと、その日の業者と揚重業者のアプリに出ます。揚重業者も書けます(「確認した」はありません。確認が必要な連絡は「この日の業者全員に連絡」を使います)。
- **履歴**: 「この日の履歴」を開くと、確定・変更・搬出確認・戻し・連絡を、いつ・だれが行ったかが新しい順に見られます。搬出確認と戻しの欄にも、押した人と時刻が出ます。

## メールのお知らせ

アプリのお知らせを、10分ごとにまとめてメールでも送ります(出来事から届くまで10〜20分ほど。GitHubの都合で遅れることがあります)。

- 業者へ: 自社へのお知らせ(確定・変更・取りやめ・当日の連絡・搬出確認の「無い」「不足」)。その会社で利用中の人全員。あなたが追加した業者(アプリを使わない業者)には送りません。
- 盛替え業者へ: 回収日の予定の確定・変更・取りやめ(その日の予定の全部つき)と、盛替えの指示。
- 管理者へ: 「設定」→「メールのお知らせ」でチェックした人にだけ、追加注文・業者や盛替え業者の登録・搬出確認の「無い」「不足」。最初は誰にもチェックが付いていません。

送るには、GitHub に FIREBASE_SERVICE_ACCOUNT・MAIL_USER・MAIL_PASS の設定が必要です(「毎朝の自動処理の設定.md」の1・4・5)。設定する前のお知らせは、1日たつと送らずに消えます。

## 追加注文の手配

業者は「業者入力」の表の「追加希望数」(または表の下の「追加注文」の欄)から、階と台数を指定して追加のNRボックスを注文できます。手配や上げた日は、業者の表の「備考(追加)」にも出ます。新しい注文があると、タブに件数が付き、カレンダーの一番上に「📦 新しい追加注文が○件あります」と出ます。

1. 「追加注文」タブの「受付中」で、用意する搬出車(これからの回収日)を選んで「手配する」を押します。業者に「○/○の搬出車で用意します」と届きます。
2. 上げたら、「手配済み」のカードで上げた日・使ったEV・台数を確かめて「上げた」を押します。業者に「✅ ○/○に○台上げました」と届き、その階の保有台数が自動で増え、「追加と戻し」の記録にも残ります。
3. 手配した日の搬出車には、当日と前日のお知らせに「📦 追加: A社 12階に3台を上げる」と出ます。

日を変えるときは「手配を戻す」、間違えて「上げた」にしたときは「上げたのを取り消す」(もう一度押すと取り消し)を押します。受けない注文は「却下」します。

**盛替え業者の「入れた」**: 手配した日になると、盛替え業者の画面に「📦 新しいBOXの搬入」が出ます。盛替え業者がエレベーターと台数を選んで「入れた」を押すと、あなたが「上げた」を押したときと同じく、注文が上げ済みになり、業者の保有台数が増えて記録も残ります。取り消しは、これまでどおり管理者の「追加注文」タブで行います。

## 台数を追加したときの記録

NRボックス(スクラップ台車)を業者に追加で渡したときは、「追加と戻し」タブで記録します。記録すると、その業者のその階の保有台数が自動で増えます。

1. 日付、業者、上げた階、台数、使ったEV、メモを入れます。
2. 「記録する」を押します。業者の「業者入力」にも増えた台数が出ます。

同じタブに、業者ごとの保有総数と追加分の累計、追加と戻しの記録が並びます。「戻し」は、「戻した」にチェックした分です。追加の記録を削除すると、その台数を保有台数から引きます。

## 集計・棚卸し

「集計・棚卸し」タブで、月ごとの集計と棚卸しができます。

- **月ごとの集計**: 月を選ぶと、業者ごとの搬出台数・搬出回数・戻し台数・「無い」「不足」の回数・追加台数・棚卸しの差・追加注文の数が出ます。「集計をCSVで保存」「明細をCSVで保存」で、Excelで開けるファイルを保存できます。明細には、日付・業者・階・台数・EV・配置・搬出確認(だれが)・戻し(だれが)が入ります。
- **棚卸し**: 業者を選び、現場で数えた実際の台数を各階に入れて「棚卸しを記録」を押すと、保有台数を実数に合わせ、差を「棚卸し」として記録に残します。一覧にない階は「ほかの階」に入れます。数えていない階は空のままにします。

## 電波が弱い場所での入力

EV前や地下などで電波がないときに押した操作は、スマートフォンに残り、つながったときに自動で送られます。送れていない間は、画面上部に「未送信 ○件」と出ます。画面を閉じても消えません。

同じ日の別の行を何人かが同時に操作しても、互いに消し合わないようになっています。台数の増減も、同時に押した分がすべて反映されます。

## 困ったとき

| こんなとき | すること |
| --- | --- |
| 「管理者」と出ず、未登録になる | 登録済みの管理者メールアドレスのGoogleアカウントでログインし直す |
| 管理者のメールアドレスなのに、業者として入ってしまう/「メールの確認がまだ済んでいません」と出る | メールアドレスとパスワードで登録した人は、届いた確認メールのリンクを押さないと管理者になれません(Googleアカウントでログインした人は不要)。リンクを押したあと、画面の「確認しました」を押します。メールが見つからないときは迷惑メールを見るか、「確認メールをもう一度送る」を押します |
| 「データを読み込めませんでした(permission-denied)」 | Firebaseのルールが古い。GitHubの firestore.rules をFirestoreの「ルール」に貼り直して「公開」 |
| 「保存できませんでした」 | 通信を確かめ、「↻ 最新にする」で読み直してもう一度入力 |
| 業者・盛替え業者が入れない | 「登録」タブで利用停止になっていないか確認し、「利用を再開」 |
| 自動確定されない | 集積するEVを選んでいるか、取り消して止めていないか確認。変更から10分以内なら待つ |
| 「未送信 ○件」が消えない | 電波のある場所でアプリを開くと送られる |
| 画面が古いまま | 「↻ 最新にする」を押すか、画面を下に引っぱる |
| SafariでGoogleログインできない | プライベートブラウズをやめて開き直す |
| LINEなどのアプリの中で開いてGoogleログインできない | メニューの「ブラウザで開く」でSafariなどで開き直す(LINEは自動でブラウザに切り替わります)。または、メールアドレスでログインする |
| 会社のメールアドレスでGoogleログインできない | そのアドレスはGoogleアカウントではありません。「新規登録はこちら」からメールアドレスとパスワードで登録する |
| Firebaseの画面で「権限がありません」 | 右上のアイコンから、Firebaseを作ったGoogleアカウントに切り替える |

データはFirebase(nr-rack プロジェクト)に保存されています。無料枠の範囲で使えています。ルールの画面: https://console.firebase.google.com/project/nr-rack/firestore/databases/default/security/rules
